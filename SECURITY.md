# UCX Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities in UCX privately to
NVIDIA's Product Security Incident Response Team (PSIRT).

Follow the instructions on NVIDIA's
[Report a Vulnerability](https://www.nvidia.com/en-us/security/report-vulnerability/)
page, or email [psirt@nvidia.com](mailto:psirt@nvidia.com).

For email reports, please encrypt sensitive information using
[NVIDIA's public PGP key](https://www.nvidia.com/en-us/security/pgp-key/).

Please include, where available:

- The affected UCX version, branch, or commit.
- The affected component and relevant system configuration.
- A description of the vulnerability and its potential security impact.
- Reproduction steps and a minimal proof of concept.
- Relevant logs or other supporting information.

Please do not disclose vulnerabilities through public GitHub issues, pull
requests, discussions, or mailing lists before coordinating disclosure
with PSIRT.

## Coordinated Disclosure

Please coordinate public disclosure with PSIRT so that the issue can be
investigated and remediation can be prepared for affected users.

See [NVIDIA's coordinated vulnerability disclosure policy](https://www.nvidia.com/en-us/security/psirt-policies/)
for further information.

## Security Advisories

Check the [UCX Security Advisories page](https://github.com/openucx/ucx/security/advisories)
for published security advisories.

For security updates affecting NVIDIA products that include UCX, also
refer to [NVIDIA Security Bulletins](https://www.nvidia.com/en-us/security/).
